HARDWARE CRASH ROOT CAUSE
- FEAR, Extraction Point, and Perseus Mandate all stopped after `weapon-db-ok` / `before-mission-db`.
- Three Vita core dumps normalize to the exact same M29AY ELF PC: 0x815f5372.
- That PC was inside a locally generated weak `strcasecmp()` wrapper that called itself recursively.
- Cause: FEARVita `stricmp -> strcasecmp` portability macro was active before Linux `ltbasedefs.h` defined its `stricmp` helper.
- Result: infinite recursion and main-thread stack overflow during MissionDB case-insensitive lookups.

M29AZ FIX
- `fearvita_msvc_compat.h` supports `FEARVITA_NO_MSVC_STRICMP_ALIASES`.
- Only runtime/kernel/src/sys/win/stringmgr.cpp receives that opt-out compile definition.
- `stringmgr.cpp.obj` now has `U strcasecmp` and does not define a weak recursive copy.
- Final M29AZ ELF has a real strong libc `strcasecmp` implementation with no self-call.
