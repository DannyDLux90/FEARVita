New milestone: menu completeness + weapon linkage.

M29AQ begins by replacing the old symbolic-only StringEdit handling with a packed SKDB v2 decoder. The retail .Strdb00p id table, packed UTF-16 string table and TOC are decoded so retail/localized menu strings can become authoritative instead of relying on the small system-language safety-net table. If the packed format fails validation the existing symbolic-id fallback remains active so the frontend can still boot.

M29AQ also adds navigation/build diagnostics for all retail screens, focused diagnostics for the Performance screen, and a weapon-menu audit that logs each default-priority weapon record plus short-name id, long-name id and silhouette icon.
