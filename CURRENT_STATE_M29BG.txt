M29BG root-cause fix:
- FEARVita's ILTStream::ReadString incorrectly treated packed LithTech strings as NUL-terminated C strings.
- Retail CGenLTStream stores strings as uint16 length + exactly N payload bytes.
- WorldBsp::Load uses ReadString for the world-model name; the old Vita implementation desynchronized the World00p stream there and caused error 42.
- The Vita adapter now matches CGenLTStream exactly, including truncation/consumption semantics.
