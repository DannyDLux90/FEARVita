Base
- Based on the uploaded M29CT 0.42-WIP source snapshot. The public main branch is still at M29AW, so this checkpoint is intentionally archived as a forward patch rather than pretending the intervening WIP snapshots are already on main.

Changes from M29CT
- Vita frontend command transitions now have one owner: CBindMgr::Update(). The direct FearVita_DispatchCommandEdges() path is no longer also fired in the Vita pre-world menu path, preventing one physical press from being delivered twice.
- Fixes the New Game/difficulty regression where one Cross could open the difficulty list and immediately confirm the default difficulty in the same frame.
- D-pad Up menu navigation follows the M29CT control remap (FLASHLIGHT instead of the old SLOWMO command).
- D-pad Down/Left/Right remain mapped to retail arrows without allowing front-touch gameplay commands to create duplicate key events.
- Both analog sticks can navigate retail menus: LS via Forward/Reverse/Strafe thresholds and RS via Pitch/Yaw thresholds.
- Cross and Triangle confirm; Circle backs out even when the Circle sprint latch turns the gameplay command into RUN; START remains Escape/back.
- Front touch remains additive mouse input.
